# Pracovní složka pro advokáta

Tato složka obsahuje pomocné tabulky k využití dokumentů z `0-data` v právním sporu se SVJ nebo s jednotlivými členy/orgány SVJ.

## Soubory

- `evidence-dukazu.csv` – inventář důkazů se základní kategorizací.
- `chronologie.csv` – časová osa, zatím s ukázkovými událostmi k doplnění.
- `finance-srovnani-vyuctovani.csv` – pracovní tabulka pro srovnání vyúčtování vlastního SVJ a konstrukčně identického vedlejšího domu.

## Poznámka ke srovnávacímu SVJ

Adresář `0-data/svj/SVJ-ve-2-identickem-dome-vyuctovani` je potenciálně významný komparativní důkaz. Pro soud však nestačí tvrzení, že dům je konstrukčně identický. Je potřeba doložit zejména:

1. stejnou nebo velmi podobnou konstrukci, plochu, počet jednotek a technické řešení domu,
2. stejné období vyúčtování,
3. stejnou metodu rozúčtování tepla, vody, TUV a služeb,
4. rozdíly v obsazenosti, spotřebách a případných haváriích,
5. zda srovnávací dokumenty pocházejí z totožného zdroje/správce a jsou úplné.

Pak lze srovnání použít k identifikaci anomálií, k dotazům na SVJ, k návrhu znaleckého/odborného posouzení a jako podpůrný argument pro požadavek na předložení podkladů nebo přepočet.
